# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in VersionDock Desktop, please report it via [GitHub Security Advisories](https://github.com/chenqinru/VersionDockDesktop/security/advisories/new) or directly contact the maintainers.

Please do not disclose security issues in public issue trackers.
