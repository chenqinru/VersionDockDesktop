# 弹窗样式与交互

普通弹窗使用 `DialogSurface`，遮罩、外框、圆角、阴影、尺寸、层级、关闭和焦点管理由公共组件及 `src/dialogStyles.css` 负责。页面只调整业务布局，不通过 `preserveStyle` 另设普通弹窗外观。设置等复杂窗口可以保留专用布局。

- 确认、输入、单选操作、多选和提交信息编辑继续通过 `dialogService` 打开，由 `DialogHost` 统一渲染；不在各业务页面复制弹窗。
- 标题使用直接子级 `header`、图标、`strong` 和 `IconButton`；按钮区域使用直接子级 `footer`，普通操作使用 `Button`。附属仓库名称可以保留标签，长标题和标签不得挤出关闭按钮。
- 服务弹窗的 `.vd-dialog-body` 管理内容滚动，标题与底部按钮不随内容滚走。选择列表使用 `.dialog-choice-body` 和 `.dialog-choices`，仅选项区域滚动。
- 选项达到 10 项时显示公共 `SearchInput`，同时匹配名称和说明，忽略大小写及搜索词两端空格。无匹配显示公共空状态；搜索不更改原始选项或清除隐藏项的勾选，下一次请求重置搜索词。
- 选项及分段切换使用 `.vd-selectable`；多选以 `aria-pressed`、切换项以 `aria-selected` 表示状态。危险选项使用 `data-danger`，默认文字、悬停、键盘聚焦和按下共用主题危险配色，不能叠加普通选中色。
- 输入框和多行输入使用 `Input`、`Textarea`；特殊编辑布局可以保留尺寸及等宽字体，焦点仍复用主题控件焦点色。
- Tab 循环、Escape、嵌套弹窗层级和关闭后的焦点恢复集中在 `DialogSurface` / `useDialogFocusTrap`。业务层只处理提交快捷键及分步操作；连续打开下一步时，旧弹窗不得抢走新弹窗焦点。

文件历史、设置、关于以及提交信息历史等专用窗口保留适合自身内容的布局和操作语义；不要为了统一外观强制使用同一宽度或把非模态浮层改成模态弹窗。
