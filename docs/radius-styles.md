# 圆角规则

`src/radii.css` 是应用圆角值的唯一入口，由 `main.tsx` 加载。组件按语义引用变量，布局密度只在根节点切换值，不再由页面各自写一组数字。

| 类型 | 变量后缀（统一前缀 `--versiondock-radius-`） | 紧凑 | 舒适 |
| --- | --- | --- | --- |
| 输入、搜索、下拉触发器、普通按钮、分段按钮 | `control` | 4px | 6px |
| 纯图标操作 | `icon` | 3px | 4px |
| 面板、内容卡片 | `panel` | 0px | 8px |
| 普通列表行、导航行 | `row` | 0px | 4px |
| 菜单、下拉、日历、提示浮层 | `popup` | 6px | 6px |
| 菜单项 | `menu-item` | 4px | 4px |
| 普通弹窗、设置、关于 | `dialog` | 12px | 12px |
| 小型矩形状态标记 | `badge` | 3px | 3px |
| 复选标记、短指示条等微小细节 | `detail` | 2px | 2px |

高度、留白、布局密度和主题配色分别由各自现有机制管理，圆角变量不引入新的状态。

## 组件与嵌套边界

- `Button`、`Input`、`Textarea`、`SearchInput`、`Select` 由公共样式管理圆角。页面只负责位置和尺寸；搜索框内部输入继续为 0，避免双层边界。
- 分段按钮由容器提供完整圆角。内部按钮的外侧角使用 `control-inner`，值为控件圆角减 1px，接缝侧为 0。只有一个子按钮时使用完整内圆角。
- 面板内紧贴外框的标题使用 `panel-inner`，值为面板圆角减 1px，最低为 0。分隔条、单侧内容区域只对需要的角引用该变量。
- AI 输入框的 SVG 描边由相同的控件圆角推导，描边路径减 0.5px。不要再单独给 SVG 或文本框写一个近似值。
- 右键菜单等使用内联布局的组件也引用同一变量；Portal 会继承根节点圆角，因此菜单打开时切换密度也保持一致。
- 同一角色在默认、悬停、选中和键盘聚焦时保持同一圆角；不要只在 hover 时补一个数字。

## 保留的专用形状

头像、圆点、开关、胶囊、计数徽章、项目/品牌图标按自身形状保留圆形、胶囊或与图标尺寸对应的圆角。滚动条、进度条、代码搜索标记及纯装饰细节保留专用形状。无独立表面的内部单元继续为 0，不能为了统一而给所有元素增加圆角。

验证两种密度下的公共控件、工作台和设置卡片、列表行、右键/筛选菜单及普通弹窗，并检查分段按钮接缝和 AI 输入描边。主题、语言或字号变化不应改变同一角色的圆角值。
