# 分支状态栏对齐验收（2026-10-02）

最终位置按用户更正：主菜单在左下角弹出；子菜单优先向右，空间不足时翻转。日志和提交面板内的分支入口继续跟随点击位置。

## 对齐内容

- 状态栏：命名分支、游离标签/提交图标；长名保留首尾；主仓库与工作树摘要；未提交、冲突、待拉取/推送计数；SVN 合并状态；工作区前台 VCS 操作的加载反馈。
- 悬停明细：仓库、分支、同步和更改表格；当前仓库、混合 Git/SVN、无上游分支、工作树及操作状态。
- 各级菜单：标题、返回、按名称/描述/最近提交搜索、方向键和 Enter、Escape 逐级返回、失焦/外部点击关闭、灰色选择反馈、视口边界处理。
- 分支与标签：公共集合去重/排序；任意 Git 仓库当前即显示当前标记；排除合成 HEAD；主分支星标；最近提交时间按界面语言格式化；正确使用操作目标仓库的当前引用；普通/强制删除保留保护分支检查。
- 冲突：打开真正的冲突工作区。SVN 普通 update 冲突无中止入口，只有跟踪到的 merge 才显示中止。
- SVN：锁定/解锁文件选择、可选锁定说明、仓库根 URL 重定位确认、主干/分支/标签切换、按名称创建分支/标签。忽略管理对齐添加/移除流程，递归查看目录属性、多选移除、写锁内重新读取属性并保留未选规则；移除初始不选中条目。

## 验证

- 前端完整检查通过：54 个测试文件、524 个测试，类型检查、lint、国际化检查及生产构建通过。
- Rust：格式、clippy、118 个测试通过。真实 Git 测试验证返回 RFC3339 提交时间；真实 SVN 测试验证跨目录忽略规则的读取、选择性移除、保留其它规则和拒绝越界路径。
