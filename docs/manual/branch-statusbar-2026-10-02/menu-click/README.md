# 分支菜单点击事件回归

原因：分支菜单是仓库标题行的 React 子节点，菜单点击向上冒泡触发仓库标题行的展开/折叠处理。

修复：在共用 BranchQuickMenu 的边界停止 click 和 doubleClick 冒泡，各级菜单及其子按钮统一隔离。

验证：新增真实 CommitPanel 交互测试，覆盖仓库初始折叠/已展开时点击其它分支、返回、分类标题及清除搜索，仓库展开状态均保持不变，仓库标题自身的点击仍有效。完整前端检查通过，54 个测试文件、525 个测试。

原生 Tauri 使用临时真实 Git/SVN 仓库，从更改标签页的 alpha 分支标签打开菜单，点击 main 展开其操作菜单。截图确认 alpha 保持折叠，未出现“没有更改”占位行；未执行检出或任何仓库写操作。
