# 更新期间提交面板数据稳定性

日期：2026-10-04。只使用 `/private/tmp/versiondock-stable-status-qa/fixtures` 中新建的临时 Git 仓库；独立 QA 标识、端口 1427、已有稳定参数及 `--no-watch`。未使用源码仓库触发更新。

## 根因与修正

自动 Shelve/Stash 会临时清空工作区，文件监听或定时刷新把该中间状态写入提交面板快照；完整刷新还会裁剪文件勾选。恢复文件后再次刷新，造成列表先消失再回来。

更新期间保留最后一份稳定快照，合并刷新请求，等实际原生响应及恢复完成后再刷新。按工作区计数协调批量、并发和其他窗口的更新；捕获刷新开始时的更新版本号，丢弃跨越备份/恢复过程的旧响应。保留 refs、history 等待处理事件，完成后一起刷新。取消和失败也释放协调状态。后台项目独立处理，fetch 不阻塞状态刷新。未修改 Rust 更新策略、通知发布机制和进度条 UI。
