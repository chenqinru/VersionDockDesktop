日期：2026-10-03。使用独立 Tauri 标识 `com.versiondock.taskprogressqa`、端口 1425、`VERSIONDOCK_STABLE_DEV=1` 和 `--no-watch`。默认启动配置未改。所有写操作只针对 `/private/tmp/versiondock-task-progress-qa/fixtures` 中新建的 Git/SVN 仓库。

## 实现及自动化检查

- 独立任务状态层，复用原生 OperationEvent；请求回调在 invoke 前绑定批量子任务，实际原生响应结束后才结束展示。
- 已知总量使用真实完成数；未知总量不估算百分比。250ms 出现、最后终态停留 2 秒、当前项目优先、稳定排序、批量主任务计数及取消后的恢复等待均有回归。
- 浮层通过 Portal 向上展开；打开时保留结果，关闭后清理本次详情，底部终态独立保留剩余 2 秒。瞬间完成的任务也能保留在已打开浮层中。
- 前端完整检查通过：元数据、独立性、窗口、国际化、类型、lint、650 项测试、生成绑定和生产构建。
- Rust 全量测试：158 项通过，1 项原有测试跳过；fmt 和全部目标／特性的 clippy 通过。
- 新增真实 Git 取消集成测试：Stash 与 Shelve 恢复完成后才返回；Stash 保留暂存和未暂存的区别。Shelve 延续既有补丁恢复语义，没有调整其策略。
