# 底部分体按钮和同步菜单验收（2026-10-03）

使用独立原生 Tauri 测试窗口和 `com.versiondock.splitbuttonsqa` 配置目录；临时 Git 仓库与本地裸仓库构造有待拉取、待推送提交的场景。

- 提交与保存分体按钮的更多入口通过 `SplitButtonMore` 共用主体的背景、前景、悬停、展开和禁用反馈；继续使用 `IconButton`，其独立灰色反馈不覆盖分体按钮。
- 同步页的同步、仅拉取、仅推送状态实拍，主按钮与更多入口保持一致。测试通过方向筛选改变显示状态，未执行底部 Git 操作。
- 菜单依据按钮边界及实测菜单尺寸向上展开，右边缘对齐按钮，保留 4px 间隔。
- 正常尺寸和 800 × 480 最小窗口中实拍菜单，底部按钮完整可见。
- 菜单高度超过可用空间时滚动显示，窗口缩放时关闭旧锚点菜单；普通指针右键菜单继续按原规则定位。这些边界行为由组件测试验证。
