# 弹窗统一设计验收

日期：2026-10-03。

## 范围与结果

用户截图用于定位旧弹窗，不作为样式参考。提交信息历史弹窗保持原有实现和视觉；设置、远程账号及远端管理保留现有内容布局和外框样式，减轻遮罩。其余弹窗统一采用12px圆角、24px内容留白、36px输入框和32px底部按钮，并复用主题色。

新增 `DialogSurface` 与 `dialogStyles.css`，基础操作、克隆／检出、忽略规则、身份、子模块指针差异、AI提示词、AI方案确认、关于及文件历史使用公共外壳。设置和账号窗口使用保留样式模式，共用层级与关闭行为。危险操作仍保留警示色，普通选中／悬停为灰色。

遮罩在深色主题为22%黑色，在浅色主题为12%深灰，背景模糊统一4px。弹窗通过 Portal 展示，嵌套时按层级置顶；Escape只关闭最上层，Tab限制在当前窗口，关闭后恢复焦点。操作期间可阻止遮罩／Escape关闭。保留输入框的初始焦点，避免被新增关闭按钮抢走。

补齐新建分支说明、关于页仓库数量标签的中文翻译；将英文AI任务标题改为可读名称。身份窗口的英文输入区域不再横向溢出。提示词和路径内容本身是业务数据，不强制翻译。
