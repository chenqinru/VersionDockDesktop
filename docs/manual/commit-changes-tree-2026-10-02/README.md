# 更改页面文件列表／树形切换验收

左侧“更改文件”工具栏增加平铺、树形按钮，默认保持原平铺视图，后续记忆用户选择。树形复用现有文件树构建器：目录优先排序、压缩单子目录、显示文件类型及目录展开图标。工具栏固定，文件区独立滚动。图标操作继续使用统一灰色反馈。

- 各仓库、已暂存／未暂存／未跟踪分别构树，不混合同路径文件和目录折叠状态。
- 单击目录只切换展开状态；支持全部展开、全部折叠。进入树形时展开目录，当前目标保持可见。
- 两种视图保留选中文件、右侧差异、比较版本和完整路径右键目标；仅切换视图不会重新请求差异。
