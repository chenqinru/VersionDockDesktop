# 远程账号、克隆与发布验收记录

验收日期：2026-10-14。当前平台：macOS。

## 已实现

- 欢迎页关联、管理远程账号，并展示账号数量；欢迎页不提供发布入口。
- 欢迎页、提交面板和空工作区共用克隆窗口，提供 URL 与账号仓库两种来源。
- 授权表单嵌入克隆流程；关联完成或取消后保留目标目录。仓库浏览显式搜索、分页去重，取消过期请求。
- 发布窗口固定工作区与仓库，显示目标分支，默认私有且推送当前分支；前后端校验发布条件。
- 后端按实际路径排斥并发发布，保留已有 Git 写锁；创建远程后重新校验本地状态，执行推送前检查分支、提交及全部推送地址。
- 远程创建后本地失败返回部分成功，保留远程与已完成步骤，禁止在当前表单重复创建。窗口内复用任务进度及取消能力。
