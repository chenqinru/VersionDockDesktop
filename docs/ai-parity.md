# AI 全量迁移清单

参考只读插件，排除 GitHub Copilot；本轮用户授权替代此前 AI 暂缓约束。

- 提供商：OpenAI Chat Completions／Responses、Claude Messages、Gemini OpenAI 接口、自定义兼容 API。
- Agent CLI：Claude、Codex、Antigravity、OpenCode，命令检测、模型、超时、取消、只读限制及会话清理。
- 提交信息：已选工作区更改、提交草稿、历史提交消息重新生成，流式写入、取消／错误恢复。
- 提交解释：单提交及跨仓库聚合，完整元数据及公平分配的 Diff 上下文。
- 代码审查：独立页，扫描／分析／验证进度、结构化结论、定位原 Diff 与变更后失效检测、复审。
- 冲突解决：当前文件所有未解决块，完整三方上下文，严格 index 校验、取消回退，预览后人工应用。
- AI 智能拆分：工作区 Git 按 hunk 拆分、SVN 按文件，拖拽多选／组重排、消息重新生成、覆盖完整校验、人工应用、状态变更拒绝与恢复。
- 历史重组：Git 连续未推送 HEAD 范围，干净工作区；保留最终 tree，隔离构建提交，备份 ref 与状态校验。
- 五类提示词：工作区优先／全局／内置，中英文，编辑、重置。
- 公共请求链：输入输出预算、上下文截断、流式进度、超时／取消、结构化结果及修复、API 密钥安全存储。

验收需区分协议模拟、真实 Git／SVN、真实提供商／CLI、原生 UI；不得将未接入入口或 mock 当作完整交付。

## 实现与运行边界

插件源码只读；Desktop 的 AI 请求、上下文、CLI 执行与 Git/SVN 写入由独立 Rust 模块负责，通过类型生成的 Bridge 接入 React。GitHub Copilot 不出现在设置选项、后端提供商列表或调用链中。

- 提交生成位于提交输入框右上角，提交选项栏仅保留审查、拆分及消息历史；提示词编辑保留在设置中。生成时输入只读，停止或失败恢复原草稿，旧请求不能覆盖新任务或其他工作区。
- 普通提交使用 HEAD 到工作区的完整所选更改；暂存模式仅使用暂存内容。混合文件审查分别提供暂存和工作区证据。
- Diff 上下文优先保留修改行及附近内容，维持真实行号；同文件未修改引用仅提供证据，不作为问题锚点。定位前重新验证完整 Diff 指纹。
- AI 冲突结果必须一次性覆盖全部请求索引，先预览再人工保存；取消、无效结果、外部文件变化或期间的人工编辑不留下部分 AI 结果。
- Git 拆分通过临时索引和隔离 worktree 构建提交，核对最终 tree，发布前重新检查 HEAD、分支、原索引和工作区。使用自己创建的 index.lock 原子发布索引，只清理自己持有的锁。未选中暂存内容、未暂存内容和 App 提交身份均保留。
- 每次 Git 发布保留恢复引用，保留最近 10 条；失败时不发布，索引发布失败时尝试 CAS 回退分支并报告恢复引用。SVN 顺序提交，部分失败明确报告已完成组数。
- Claude / Codex 使用无持久会话模式；Antigravity 按工作目录串行复用并保存会话映射，失效时替换一次，可手动重置；OpenCode 在成功、失败、取消后清理临时会话，失败的清理记录在下次检测或执行时重试。
- 密钥仅存系统 keyring；应用配置、提示词、日志和前端状态不存密钥。CLI 模式不读取 API 密钥。
