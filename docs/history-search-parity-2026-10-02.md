# 搜索区对齐记录

参考只读插件仓库的 `CommitFiltersBar.tsx`、Git 日志 `main.tsx`、`logStore.ts` 和 Git/SVN 查询实现；在 Extension Development Host 与原生 Tauri App 中使用同一套临时 Git 仓库核对。范围包含主日志搜索栏、比较视图两侧的搜索栏，以及文件／选区历史条件。AI 与舒适布局不在范围内。

## 功能与界面

| 项目 | 对齐结果 |
| --- | --- |
| 提交搜索 | 文本与正则沿用真实后端查询，支持提交哈希；输入后 250ms 查询，Enter 立即执行，清除和 Escape 立即生效；处理中文输入法组合输入及未完成输入的取消 |
| 作者 | 用邮箱区分同名作者，无邮箱时用姓名；按唯一仓库提交计数，展示头像、姓名、邮箱、数量和选中标记；菜单按姓名／邮箱过滤，Enter 选择已有候选，不再创建插件没有的自定义作者 |
| 作者候选范围 | 按当前查询结果重建，分页时累计；比较视图两侧使用主日志同一组候选，独立选择条件。没有新增跨查询作者缓存 |
| 仓库 | 多仓库时显示，单仓库时隐藏；大写名称、颜色圆点、全部仓库和单选；选中后关闭菜单 |
| 分支／标签 | 本地分支与标签分组，按名称过滤；同名项目合并仓库作用域，发送完整 Git ref；选中标签显示 tag 图标，远程侧栏选择不会插入本地候选列表 |
| 日期 | 宽度达到 310px 显示双月，否则单月；各月独立前后翻页、范围预览、反向选取自动排序；选完终点自动关闭，触发器内提供独立清除动作 |
| 隐藏历史筛选 | 文件历史的“在提交历史中显示”及差异行右键“显示选区历史”进入后展示“历史：文件名／行号”标签。单独清除只移除路径、行范围及隐式历史版本，保留当前其它筛选；清除全部完整重置 |
| 更多操作 | 保留抓取并刷新；多仓库显示展开／收起项目名称，单仓库隐藏此项。图标动作继续使用共享灰色反馈 |
| 下拉交互 | 统一触发器与弹层尺寸、边框、间距、阴影；菜单选中、日历范围使用用户指定的灰色语义。支持 Escape、外部点击和窗口失焦关闭；比较两侧的单选组互不干扰 |
| 窄窗口 | 移除隐藏筛选项的旧规则；在最小窗口宽度 800px 下允许搜索栏换行，所有筛选仍可操作 |

删除重复作者统计、比较搜索的第二次 250ms 防抖、无调用方的筛选参数和原生日历旧样式。新增查询条件更新时的旧请求取消，防止迟到响应覆盖当前结果。

## 日期截图纠正

用户新对照截图进一步指出日期栏和清除全部按钮的差异。根因是 `.filter-button > span` 同时匹配了 `Codicon` 输出的 span，日期清除预留空间扩大了图标宽度，使文字偏左且清除图标与箭头挤在一起；日历还沿用了普通菜单的背景和额外网格间距。

改为明确的 `.filter-label` 和清除占位；选中日期文字居中，独立清除按钮与箭头分别占位。主日志与比较两侧共用 `DateFilter`，未完成范围统一显示 `YYYY-MM-DD → ...`。日期弹层使用插件的 dropdown/editor 背景，星期与日期合并为一个网格，对齐月份导航及行间距；保留灰色端点和范围反馈。

按最新截图，“清除全部筛选”图标恢复插件的红色错误语义，按钮继续使用共享灰色 hover；清除全部与更多按钮按插件保持 4px 间距。

最新完整前端检查通过（53 个文件、539 个测试），本轮未改 Rust 代码。原生 Tauri 使用同一真实 Git fixture 验证仅选择 2026-10-13 时两个面板均显示十月、两处 13 有灰色选中、标题居中、清除/箭头分离及清除全部图标为红色；清除日期后标题恢复且清除全部按钮消失。截图和日志位于 `docs/manual/history-search-2026-10-02/date-correction/`。独立 QA 进程退出、配置恢复，用户现有进程保留。
